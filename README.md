# Big Brother

an extension that makes sure you aren't slacking off

## Install

1. open extensions on chrome or edge
2. turn developer mode on
3. click load unpacked and add the folder

Allow access to all websites when prompted so redirects can work.

## Use

Add websites to block them & remove them to unblock them! Once you add a website, though, there is a 24
hour period in which you cannot remove it.

The popup shows the cooldown remaining. After 24 hours, a Remove button appears and unblocks the
domain immediately when clicked. Domains stay blocked until you explicitly remove them, including
across browser restarts.

When upgrading from the previous removal-delay version, existing pending deadlines become cooldown
deadlines. Older entries without a recorded deadline start a one-time 24-hour cooldown on upgrade,
since the previous version did not store when they were added.
